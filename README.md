# 113-Notepad_project (個人助理筆記本)

這是一個基於 Python Tkinter 開發的個人助理應用程式，整合了日曆、待辦事項和富文本筆記本功能，並支援深色/淺色模式切換，幫助您有效管理日常生活與工作。

## ✨ 主要功能

*   **首頁儀表板 (Dashboard)**: 快速概覽，提供各功能的快捷入口。
*   **萬年曆 (Calendar)**:
    *   瀏覽任意年份與月份。
    *   日期上會有圖示標記當天是否有待辦事項 (不同圖示代表不同狀態)。
    *   點擊日期可快速新增筆記或檢視當日事項。
*   **待辦事項 (Todo List)**:
    *   新增、刪除待辦事項。
    *   設定詳細的日期與時間提醒。
    *   支援過期事項自動標示與清理功能。
*   **記事本 (Note Text Editor)**:
    *   富文本編輯功能（粗體、斜體、底線）。
    *   自訂字型、大小、顏色與對齊方式。
    *   支援儲存與另存新檔 (.txt)。
*   **深色/淺色模式 (Dark/Light Mode)**: 內建護眼深色模式與明亮淺色模式，可隨時一鍵切換，適應不同環境光線。
*   **響應式側邊欄**: 可展開或收合的側邊選單，提供直覺的導航體驗。

## 🛠️ 安裝說明

在使用本專案之前，請確保您的系統已安裝 Python 3.x。

### 1. 安裝相依套件

本專案需要以下 Python 第三方函式庫：

*   `Pillow`: 用於處理圖片與圖示。
*   `tkcalendar`: 用於日曆選單與日期選擇。

請開啟終端機 (Terminal) 或命令提示字元 (CMD) 執行以下指令安裝：

```bash
pip install Pillow tkcalendar
```

### 2. 專案結構

請確保專案目錄包含以下檔案與資料夾，以確保程式正常運作：

*   `main.py`: 程式主入口點。
*   `homeFM.py`, `notecalendarFM.py`, `notetextFM.py`, `notetodoFM.py`: 功能模組檔案。
*   `icon/`: 存放應用程式所需圖示的資料夾 (如 `feather-pen.png`, `menu-burger.png` 等)。
*   `tasks.txt`, `notes.txt`: 用於儲存使用者資料的檔案 (程式會自動建立)。

## 🚀 使用方法

1.  開啟終端機並切換到專案目錄。
2.  執行 `main.py` 啟動應用程式：

```bash
python main.py
```

3.  **操作指南**:
    *   點擊左上角的 **Menu** 圖示可展開或收合側邊欄。
    *   點擊左下角的 **太陽/月亮** 圖示可切換 深色/淺色模式。
    *   透過側邊欄按鈕切換 **日曆**、**記事本** 或 **備忘錄** 功能。

## 📝 注意事項

*   待辦事項過期 30 天後系統會自動進行清理。
*   請勿隨意刪除 `icon` 資料夾內的圖片，以免程式報錯。
